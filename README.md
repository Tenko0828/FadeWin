# 窗口褪色 FadeWin

一个 macOS 菜单栏小工具：**窗口越久没碰，就越淡**。你正在用的窗口保持清晰；被遗忘的窗口一点点变透明、蒙上磨砂，边缘留一圈液态玻璃的轮廓；点它一下，立刻恢复。

和「压暗非活动窗口」类的工具不同：那类是一切换就立刻变暗，这里是**随闲置时间慢慢褪色**。褪得深浅本身就是一个提醒——哪些窗口早就被你忘了，一眼能看见。

## 它能帮你做什么

- **专注**：桌面上开着十几个窗口时，只有手头这一个是清晰的，其余的自动退到背景里，不再抢注意力。
- **隐私**：离开座位、共享屏幕、别人从身后路过时，没在用的窗口（聊天、邮件、文档）已经被磨砂挡住，看不清上面的字。
- **找回被遗忘的东西**：越淡的窗口越久没碰过；菜单栏「被遗忘的窗口」按闲置时间列出来，点一下叫回前台。
- **桌面更清爽**：透视外观下，不用的窗口几乎透明，能看到它后面的壁纸和其他窗口，桌面不再一层压一层。

## 功能

- **三种外观**（菜单栏「外观」里切换）
  - **透视**（需要屏幕录制权限）：窗口越久没碰越透明，能看到它后面的东西；边缘是**液态玻璃边框**——后面的画面在边缘被折射弯曲、红绿蓝三色错开（色散）、左上带高光，褪尽之后轮廓依然清楚
  - **液态玻璃**（macOS 26+）：盖一块越来越厚的磨砂玻璃，内容逐渐虚化
  - **纯色薄雾**：盖一层越来越浓的白（深色模式下是黑）雾
- **隐私薄雾**（透视外观，默认开）：窗口自己的内容被磨砂挡住，后面的东西照样透出来
- **看视频不褪色**：正在播放视频的窗口不会褪（哔哩哔哩客户端、Chrome 等会被直接识别；其他播放器、静音视频靠“画面在不在动”识别）
- **锁定**：⌥⌘L 锁定当前窗口，它就不再褪色；也可以把某个 App 设成「永不褪色」
- **快捷键**：⌥⌘P 暂停/继续，⌥⌘R 所有窗口立刻恢复，⌥⌘L 锁定/解锁当前窗口
- 雾层**不拦截鼠标**：点下去直接点到窗口，窗口约 0.3 秒平滑恢复
- 拖动窗口、点壁纸显示桌面、三指上滑进入调度中心时，雾层先隐藏，窗口停稳后再淡回来
- 窗口被拖到屏幕边缘时，被截断的一侧不画圆角和边框
- 四档速度：演示（3 秒 / 12 秒，用来快速看效果）、快（15 秒 / 90 秒）、中（1 分钟 / 10 分钟，默认）、慢（5 分钟 / 1 小时）；括号里是「多久后开始褪」/「多久褪到最浅」
- 浅色 / 深色模式自动适配；支持开机自启动

## 安装

需要 macOS 13 及以上（液态玻璃外观需要 macOS 26），以及 Xcode 或 Command Line Tools（`xcode-select --install`）。

```bash
git clone https://github.com/Tenko0828/FadeWin.git
```

```bash
cd FadeWin && ./build.sh install
```

只想打包不安装的话运行 `./build.sh`，产物在 `build/FadeWin.app`。App 使用本地临时签名（ad-hoc），只适合在自己的电脑上编译使用。

## 权限

- **液态玻璃**和**纯色薄雾**外观不需要任何权限。
- **透视**外观需要「屏幕录制」权限（“画面在动”的视频识别也只在透视外观下运行；选玻璃或薄雾时完全不抓屏，系统不会亮录屏指示）：在菜单栏「外观」里选透视，按提示到「系统设置 → 隐私与安全性 → 屏幕录制」里允许 FadeWin，然后退出重开一次。没授权时会自动用玻璃顶着。macOS 对常驻的录屏 App 会定期弹出「是否继续允许」，属于系统行为。
- 所有处理都在本机完成，不联网，不保存任何截图。

## 原理

- **透视**：macOS 不允许一个 App 修改另一个 App 窗口的透明度（私有接口也会被系统忽略），所以这里是用 ScreenCaptureKit 实时抓取「去掉这个窗口和它前面所有窗口之后的屏幕」，贴在窗口上方，再按闲置时间变淡，叠起来就像窗口本身变透明了。最多同时透视 8 个窗口，按前后顺序分配，被完全挡住的窗口不抓取。
- **玻璃边框**：一个 Core Image 着色器，按圆角矩形的距离场把边缘一圈的背景往里折射，三个颜色通道折射量不同形成色散。
- **视频识别**：一是读系统里“别让屏幕休眠”的申请（播放器常会申请）；二是以 64×40 的极低分辨率、每秒 2 帧看快要褪色的窗口，大块区域持续变化就算在放视频。
- **节能**：动画跟随屏幕刷新、没东西要动时暂停；窗口列表先只取编号，没变化就复用；被挡住的窗口停止抓取。几个窗口同时透视时 CPU 约 9%，没有窗口在褪色时约 1%。

## 已知限制

- 透视画面有几十毫秒延迟；拖动或缩放窗口时雾层会先隐藏，停稳后再出现
- 圆角是固定值，个别窗口的圆角和它对不齐时边角会有细小错位
- 正在放视频的浏览器，它所有窗口都不褪色（按 App 识别时没法细分到窗口）
- 多显示器没有充分测试

## 代码结构

| 文件 | 内容 |
| --- | --- |
| `Sources/FadeWin/Fader.swift` | 窗口列表、闲置计时、雾层、动画、锁定与例外 |
| `Sources/FadeWin/SeeThrough.swift` | 透视用的屏幕抓取 |
| `Sources/FadeWin/GlassRim.swift` | 玻璃边框着色器、透视雾层的视图 |
| `Sources/FadeWin/VideoWatch.swift` | 按“别让屏幕休眠”的申请识别视频 |

| `Sources/FadeWin/Hotkeys.swift` | 全局快捷键 |
| `Sources/FadeWin/Hud.swift` | 操作提示 |
| `Sources/FadeWin/main.swift` | 菜单栏、图标渲染、开机启动 |
