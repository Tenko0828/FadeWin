# 窗口褪色 FadeWin

一个 macOS 菜单栏小工具：**窗口越久没碰，就越淡**。你正在用的窗口保持清晰，被遗忘的窗口一点点蒙上一层薄雾，最后几乎融进背景；一点它，立刻恢复。

和「压暗非活动窗口」类的工具不同：那类是一切换就立刻变暗，这里是**随闲置时间慢慢褪色**。颜色深浅本身就是一个提醒——哪些窗口早就被你忘了，一眼能看见。

## 功能

- 每个窗口单独计时：多久没聚焦，褪得就有多深
- 两种外观（菜单栏「外观」里切换）：**液态玻璃**（macOS 26+ 默认）——窗口上盖一块越来越厚的磨砂玻璃，内容逐渐虚化；**纯色薄雾**——盖一层越来越浓的白（深色模式下是黑）雾，内容始终看得见
- 雾层完全**不拦截鼠标**，点下去直接点到窗口，窗口立刻恢复清晰
- 菜单栏「被遗忘的窗口」：列出闲置超过 5 分钟的窗口，点一下把那个 App 叫回前台
- 四档速度：演示（3 秒 / 12 秒，用来快速看效果）、快（15 秒 / 90 秒）、中（1 分钟 / 10 分钟，默认）、慢（5 分钟 / 1 小时）；括号里是「多久后开始褪」/「多久褪到最浅」
- 可随时暂停；浅色 / 深色模式自动换雾的颜色；支持开机自启动

## 安装

需要 macOS 13 及以上，以及 Xcode 或 Command Line Tools（`xcode-select --install`）。

```bash
git clone https://github.com/Tenko0828/FadeWin.git
```

```bash
cd FadeWin && ./build.sh install
```

只想打包不安装的话运行 `./build.sh`，产物在 `build/FadeWin.app`。App 使用本地临时签名（ad-hoc），只适合在自己的电脑上编译使用。

## 权限

不需要任何权限。它只读窗口的位置和所属 App，不截屏。因此「被遗忘的窗口」里通常只显示 App 名，不显示窗口标题（读标题需要屏幕录制权限，这里刻意没要）。

## 已知限制

- **不是真透明**：macOS 不允许一个 App 修改另一个 App 窗口的透明度（私有接口也会被系统忽略），所以这里是在窗口上方盖一层效果，窗口本身并没有变透明。想做到「透过窗口看到后面」需要屏幕录制权限，目前没做

- 同一个 App 里没在最上面的窗口也会按闲置时间褪色（这是特意的）
- 雾层跟随窗口每 0.5 秒更新一次，拖动窗口时雾会稍有滞后
- 以窗口为单位，不识别窗口里的内容
